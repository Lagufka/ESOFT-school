# ESOFT school
Репозиторий для прохождния тестовых заданий в школу программирования в ESOFT

## Структура папок
- `house_task` - содержит файлы для 1 задания с веб страницей дял визуализации дома
- `copy_task` - содержит файлы для 2 задания с JS файлами для копирования сложных объектов и тестировки этого копирования
- `copy_task` - содержит файлы для 3 задания с JS файлами для алгоритма определения правильности последовательности скобок и тестировки этого алгоритма
